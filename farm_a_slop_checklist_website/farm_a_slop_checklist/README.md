# Farm a Slop — Dev Checklist

## Preview locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Sign in to GitHub or create an account at https://github.com.
2. Click the `+` button in the top-right and choose **New repository**.
3. Name it `farm-a-slop-checklist`. Set it to **Public** and create the repository.
4. Choose **Add file → Upload files**, then upload `index.html` from this folder. You can also upload this README.
5. Click **Commit changes**.
6. Open the repository's **Settings → Pages**.
7. Under **Build and deployment**, select **Deploy from a branch**.
8. Select branch **main** and folder **/(root)**, then click **Save**.
9. Wait a minute or two. The Pages section will show your website URL, usually:
   `https://YOUR-GITHUB-USERNAME.github.io/farm-a-slop-checklist/`
10. Open that URL and send it to your friend.

## Important sharing note
This static site saves checkmarks, assignments, and notes in the current browser only. GitHub Pages does not provide shared live syncing by itself. Use **Export & share progress** to download a JSON progress file and send it to your friend. To make changes sync live between both people, you would need to connect the site to a shared backend/database or use a collaborative task app.
